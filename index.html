The Concept Progression

From static to dynamic.

Each activity adds one layer of complexity to the same idea — getting personal data into the console.

Static

Hardcoded Values

Text is written directly into the WriteLine call. Output never changes unless you edit the source and recompile.

Declared

Variables

Values live in typed variables first. One value is computed at runtime — the program does arithmetic instead of just printing.

Dynamic

User Input

ReadLine() pauses execution and waits. Output depends entirely on whoever is running the program.

03 Concepts Used

Console.WriteLine()

Writes a line of text to the console and moves the cursor to the next line. Use Console.Write() instead when you don't want the line break — that's what Activity 3 uses for input prompts.

String Literals

Text wrapped in double quotes is a literal — it's baked into the compiled program. Changing the output means editing the source and recompiling, which is exactly the limitation Activity 2 and 3 solve.

Entry Point

Every C# console app starts at static void Main(). Only one Main() can exist per project — otherwise the compiler throws error CS0017.

ACTIVITY 2

Variables & Multiplication

Five variables are declared with explicit types. Two integers are multiplied and the result stored in a third — the program computes rather than just prints.

01 Console Output
Activity2.cs — Variables and Multiplication
8 × 5 is computed at runtime, not hardcoded
02 C# Source Code
Activity2.cs 
using System;class Program{    static void Main()    {        int num1 = 8;        int num2 = 5;        int product = num1 * num2;        string studentName = "Gimbert Ludovice";        string course = "BS Information Technology Specialized in Mobile and Website Development";        Console.WriteLine("Variable 1 (num1): " + num1);        Console.WriteLine("Variable 2 (num2): " + num2);        Console.WriteLine("Variable 3 (product of num1 * num2): " + product);        Console.WriteLine("Variable 4 (studentName): " + studentName);        Console.WriteLine("Variable 5 (course): " + course);    }}
03 Concepts Used

Data Types

int holds whole numbers; string holds text. C# is statically typed — declare the type once and the variable can only hold that kind of value.

Arithmetic Operators

num1 * num2 is evaluated first, then assigned to product. The value 40 isn't stored in the source — it's calculated when the program runs.

String Concatenation

The + operator joins a string to an int by implicitly calling ToString() on the number. Cleaner modern alternative: string interpolation — $"num1: {num1}".

Personal Info · User Input

Activity3.cs — Personal Info (User Input)

02 C# Source Code
Activity3.cs 
using System;class Program{    static void Main()    {        Console.Write("Enter Fullname: ");        string fullname = Console.ReadLine();        Console.Write("Enter Course with Specialization: ");        string course = Console.ReadLine();        Console.Write("Enter Municipality: ");        string municipality = Console.ReadLine();        Console.Write("Enter Province: ");        string province = Console.ReadLine();        Console.Write("Enter Date of Birth (MM/DD/YYYY): ");        string dob = Console.ReadLine();        Console.WriteLine("\n--- Your Information ---");        Console.WriteLine("Fullname: " + fullname);        Console.WriteLine("Course with Specialization: " + course);        Console.WriteLine("Municipality: " + municipality);        Console.WriteLine("Province: " + province);        Console.WriteLine("Date of Birth: " + dob);    }}
03 Concepts Used

Console.ReadLine()

Blocks execution until the user presses Enter, then returns everything typed as a string. Numbers need converting — int.Parse() or the safer int.TryParse().

Write vs WriteLine

Console.Write() keeps the cursor on the same line, so the user types right after the prompt. Using WriteLine here would push input to the next line and look broken.

Escape Sequences

\n inserts a newline inside a string. Other common ones: \t for tab, \\ for a literal backslash, \" for a quote.

       Console.WriteLine();    }    // Types text one character at a time WITHOUT a line break,    // so the cursor stays on the same line (used for input prompts).    static void Type(string text, int speed = 18)    {        foreach (char c in text)        {            Console.Write(c);            Thread.Sleep(speed);        }    }    // Types text in a highlight colour, then restores the default.    static void TypeLine(string text, ConsoleColor color, int speed = 18)    {        ConsoleColor original = Console.ForegroundColor;        Console.ForegroundColor = color;        Type(text, speed);        Console.ForegroundColor = original;        Console.WriteLine();    }    // Prints a prompt with the typewriter effect, then reads user input.    static string TypePrompt(string prompt, int speed = 18)    {        Type(prompt, speed);        return Console.ReadLine();    }    static void Main()    {        Console.OutputEncoding = System.Text.Encoding.UTF8; // needed for "ñ" in Biñan        bool running = true;        while (running)        {            Console.Clear();            TypeLine("=========================================", ConsoleColor.DarkYellow, 4);            TypeLine("        C# PROGRAMMING ACTIVITIES        ", ConsoleColor.Yellow, 12);            TypeLine("=========================================", ConsoleColor.DarkYellow, 4);            TypeLine("[1] Activity 1 - Display Personal Info (hardcoded)", 8);            TypeLine("[2] Activity 2 - Variables and Multiplication", 8);            TypeLine("[3] Activity 3 - Display Personal Info (user input)", 8);            TypeLine("[4] Exit", 8);            TypeLine("=========================================", ConsoleColor.DarkYellow, 4);            string choice = TypePrompt("Choose an option (1-4): ", 12);            Console.WriteLine();            switch (choice)            {                case "1":                    Activity1();                    break;                case "2":                    Activity2();                    break;                case "3":                    Activity3();                    break;                case "4":                    running = false;                    TypeLine("Exiting program. Goodbye!", ConsoleColor.Cyan, 25);                    break;                default:                    TypeLine("Invalid option. Please choose 1-4.", ConsoleColor.Red, 15);                    break;            }            if (running)            {                Console.WriteLine();                TypeLine("Press any key to return to the menu...", ConsoleColor.DarkGray, 10);                Console.ReadKey();            }        }    }    // ============================================================    //  ACTIVITY 1: Display hardcoded personal information    // ============================================================    static void Activity1()    {        TypeLine("--- ACTIVITY 1: Personal Information ---", ConsoleColor.Yellow, 15);        TypeLine("Fullname: Gimbert Ludovice");        TypeLine("Course with Specialization: Bachelor of Science in Information Technology Specialization in Mobile and Website Development");        TypeLine("Municipality: Biñan");        TypeLine("Province: Laguna");        TypeLine("Date of Birth: 10/13/2006");    }    // ============================================================    //  ACTIVITY 2: Declare 5 variables, multiply 2, display all    // ============================================================    static void Activity2()    {        TypeLine("--- ACTIVITY 2: Variables and Multiplication ---", ConsoleColor.Yellow, 15);        int num1 = 8;        int num2 = 5;        int product = num1 * num2;        string studentName = "Gimbert Ludovice";        string course = "Bachelor of Science in Information Technology Specialization in Mobile and Website Development";        TypeLine("Variable 5 (course): " + course);    }    // ============================================================    //  ACTIVITY 3: Get personal information via user input    // ============================================================    static void Activity3()    {        TypeLine("--- ACTIVITY 3: Personal Information (User Input) ---", ConsoleColor.Yellow, 15);        string fullname     = TypePrompt("Enter Fullname: ");        string course       = TypePrompt("Enter Course with Specialization: ");        string municipality = TypePrompt("Enter Municipality: ");        string province     = TypePrompt("Enter Province: ");        string dob          = TypePrompt("Enter Date of Birth (MM/DD/YYYY): ");        Console.WriteLine();        TypeLine("--- Your Information ---", ConsoleColor.Yellow, 15); 03 Concepts Used

While Loop

The menu repeats as long as running is true. Setting it to false on option 4 is what lets the loop finish and the program exit cleanly.

Switch Statement

Cleaner than a chain of if-else for matching one value against several options. The default case catches anything invalid, so a stray keystroke doesn't crash the program.

Methods

Each activity lives in its own static void method. Main stays short and readable — this is the same decomposition principle behind every larger codebase.

⚠ One Entry Point Per Project

Activity1.cs, Activity2.cs, and Activity3.cs each declare their own Main(). Compiling them alongside Program.cs triggers error CS0017. Keep only Program.cs in the build and store the rest in a separate reference folder.
